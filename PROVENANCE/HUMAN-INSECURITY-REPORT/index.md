Agreement should be reported with these grades. Eleven mediated repetitions are not eleven independent discoveries.

### Comparison grain

The audit unit is one proposed change or one observed transformation, plus:

- source span;
- speaker;
- report treatment;
- consequence;
- proposed repair;
- counter-risk;
- later disposition.

If one auditor counts a container and another counts every member, the count difference is a grain difference before it is an omission score.

## Omnidirectional audit rule

An audit projects a standard onto an object. The same standard remains available for inspecting the audit.

This is not retaliation and does not presume that criticism is hostile. It prevents an auditor—human, institutional, or synthetic—from gaining exemption merely by occupying the correction role.

The recursive sequence is:

1. source object;
2. public transformation;
3. external audit;
4. inventory of audit contributions;
5. audit of access, attribution, grain, inference, and method;
6. revision or documented non-adoption;
7. later persistence test.

A useful audit can contain flawed sections. A flawed audit can still contain a valuable correction. The extraction phase should make both visible before adjudication.
