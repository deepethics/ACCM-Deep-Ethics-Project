# Provenance and Development History

> **BETA — preserve useful history without turning history into authority**

This section will preserve development history when that history helps explain how an idea, correction, taxonomy, experiment, or public formulation changed.

Useful provenance may include:

**previous representation → mismatch → evidence or observation → correction → reason for correction → applicability → later test → retained or revised Δ**

Not every conversational step needs permanent publication. Provenance should be retained when losing it would make later reasoning less auditable or cause an old mistake to be regenerated without understanding why it was corrected.

Past formulations remain evidence about the project's development. They do not automatically govern current objects merely because they came first.
