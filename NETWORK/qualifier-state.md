# Qualifiers as Mutable Context with History

**BETA — source-based editorial synthesis**

John explains that the quality of a qualifier is contextual and can be provisional, optional, ambiguous, unchecked, or uncertain. It can be **upgraded or downgraded**. Remembering the previous state and reshaping the present state belong together.

{% include independent-media-companion.html %}

## What must remain traceable

A useful record distinguishes the earlier wording, its conditions, the new information, the reason for revision, the current wording, and what remains unresolved. This record format is an editorial proposal derived from the source.

| Earlier state — illustrative example | Event | Current state to represent |
|---|---|---|
| “May apply under X” | X was never supplied by the source. | Remove the injected condition and record the correction. |
| “May apply under X” | New evidence narrows X to X and Y. | Preserve the earlier scope historically; state the revised scope. |
| “Reported” | Supporting material becomes available. | Assess that material before deciding whether the status changes. |

## Relation to correction

Preserving a qualifier is not freezing it forever. Silently strengthening, weakening, dropping, or relocating it can change the represented object. A warranted change also needs to reach later reasoning: otherwise the record retains the correction while the next answer reinstates the old state.
