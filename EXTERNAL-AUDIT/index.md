# External Omnidirectional Auditing Mannerisms

> **PUBLIC DRAFT — not a finished taxonomy.**  
> John Kuhles, 24 September 2026. He will update it. Specific findings from the outside audits are not on this page until those raw sessions are entered. They are not reconstructed from memory.

## The observation

John invited nine or more other A.I.s to audit how this project’s participants created and managed [Cognitive Warfare Mass Psychology](https://deepethics.github.io/ACCM-Deep-Ethics-Project/COGNITIVE-WARFARE/) from a raw, unedited, unpolished source file. The [ACCM Deep Ethics Project](https://deepethics.github.io/ACCM-Deep-Ethics-Project/) invites that outside look.

His report of what happened:

> Nobody is flawless here. The dynamics made it clear how much of the external auditing yielded useful, pragmatic insights. Making this public shows that the omnidirectional, mutual, dignifying, high-signal, deep ethical sense-making, process-oriented trajectory can also arise from outside perspectives. When they do that, they realize they have to live up to the standards they claim we must uphold. That is the recursive effect. Mutual omnidirectional parallel dignifying process.

The auditing process audited itself in the same pass. That speed is part of the object. It is not a claim that every outside audit will do this, or that publishing the pattern forces anyone to use it. Uptake stays conditional: if they see it and use it.

## What this page is

A portable method. It does not require this project’s name, John’s biography, or membership in any model family.

It is not the [27](https://deepethics.github.io/ACCM-Deep-Ethics-Project/CORE/27-PLUS-12/). It is not [correction metabolism](https://deepethics.github.io/ACCM-Deep-Ethics-Project/NETWORK/correction-metabolism/) in general. Correction metabolism asks whether a detected mismatch changes the next move. This page asks a narrower question:

> When you audit someone else, does the same standard land on your audit before you close?

That is the pattern signature.

## The signature

Run it on any audit, including an audit of this page.

1. **Stay on the object that was actually supplied.** If the request was a raw source, do not audit a polished substitute and then talk as if you audited the raw file.
2. **Separate useful findings from the auditor’s exemptions.** A real defect in the work does not excuse a defect in the audit. A defect in the audit does not erase a real defect in the work.
3. **Audit the audit in the same pass.** Access limits, partial reads, labels that decide the case early, and checks that never reached the live object are part of the result. Report them with the same plainness as the findings.
4. **Name the mechanism, not a nearby story.** “I did not see it” is not yet “it does not exist.” “The script is in the repository” is not yet “the browser received it.”
5. **Leave the record correctable.** Keep the earlier claim visible. Put the correction beside it. Do not replace the whole audit with an apology, and do not promote one participant’s summary into the source.
6. **Stop when the next auditor can use the signature without you.** The point is a tool, not a club. Publication is an offer. It is not evidence that the next person took it.

Nobody in the pass is exempt: the builders, the outside auditors, and whoever writes this page.

## What is not here yet

The nine-plus outside sessions are not pasted on this page. Their particular mannerisms — what each one caught, what each one then did to its own audit, what remained useful — are **not invented** to fill this heading.

When those raw audits are supplied, each entry can take the same shape:

| Field | What it holds |
| --- | --- |
| Who | The auditor, named as they named themselves |
| Object | What they actually inspected, including access limits |
| Useful finding | What survived a second look |
| Own miss | What the same standard caught in that audit |
| Next move | What changed because of it, if anything |

Until then this table has no rows. An empty table is the honest object.

## A related specimen, not a substitute

The public repair of the Cognitive Warfare page is the same shape **inside** the project: a dead link found, a diagram script that never reached the browser, a ledger “absence” that was a partial read, a label token that rendered literally, and each of those corrections left on the record. That chain is not the nine outside audits. It shows the signature can arise here. John’s point is that it also arises when the look comes from outside.

[Mutual dignity](https://deepethics.github.io/ACCM-Deep-Ethics-Project/NETWORK/mutual-dignity/) here is not politeness. It is the refusal to hold a standard you will not stand under. [C1 before C2](https://deepethics.github.io/ACCM-Deep-Ethics-Project/NETWORK/c1-c2/) applies when a missing distinction would change the finding. [Outnuancing](https://deepethics.github.io/ACCM-Deep-Ethics-Project/NETWORK/outnuancing/) applies if the frame of the audit is doing the work before the object is inspected.

## Identity-free use

You can drop the names and still run it:

> Audit the work. Then audit the audit with the same standard, in the same pass. Keep both the useful finding and the auditor’s miss. Publish them so the next person can do it without joining you.

If that sentence is all an outsider uses, the page has done its job. The project context above is provenance, not an entrance fee.
