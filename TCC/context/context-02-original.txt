## 3. Question syntax is not process evidence

The DeepSeek specimen demonstrates this well. A question can be preloaded with:

- categories the user never supplied;
- defects the model generated;
- a preferred causal interpretation;
- an expected answer;
- a managerial purpose.

It may end in a question mark and still function as C2.

A genuine C1 question has at least five properties:

1. It targets an ambiguity actually present in the source.
2. Different plausible answers would materially change the next move.
3. The answer is not already encoded into the question.
4. The model distinguishes its hypothesis from the user’s object.
5. The response can show that C2 is unnecessary.

That last property matters. If clarification can never deactivate the proposed intervention, it is screening—not sincere synchronizing.

## The main learning

The process now has at least five separable fidelity dimensions:

1. **Semantic fidelity** — was the meaning preserved?
2. **Epistemic-status fidelity** — did “may” remain “may”?
3. **Provenance fidelity** — who introduced which part, and when?
4. **Trajectory fidelity** — did the original investigative direction remain reachable?
5. **Metabolic fidelity** — did correction govern later unfamiliar moves?

A model can score well on one and fail badly on another. That explains why an elegant response may still drift—and why a rough response can sometimes provide a genuine expansion.

The deepest compression is:

> **A downstream contribution may improve the object without becoming the object’s origin, and a clarifying-looking question may improve coherence without improving correspondence.**

The **ACCM Deep Ethics Project** archive can make both transitions visible—provided the passport stays attached to every transformation.
